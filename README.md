# 🩺 Diabetes Risk Prediction System
UI : https://aiasg-diabetespredictor-bwb8fcovyyatpagw3rwmyy.streamlit.app/

## Overview

The **Diabetes Risk Prediction System** is a Machine Learning web application developed using **Python** and **Streamlit** to predict whether a person is at **Low Risk** or **High Risk** of diabetes based on several health-related features.

The system applies trained machine learning models to provide fast and user-friendly diabetes risk predictions, helping users better understand their potential health status.

---

## Features

* User-friendly Streamlit interface
* Predicts **High Risk** or **Low Risk** of diabetes
* Uses trained Machine Learning models
* Input validation for user data
* Displays prediction result instantly
* Supports multiple machine learning algorithms
* Responsive web interface

---

## Machine Learning Models

The project compares the performance of several machine learning algorithms:

* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Random Forest (Best Performing Model)

The Random Forest model is used for prediction in the deployed application because it achieved the highest performance.

---

## Dataset

The project uses the **Pima Indians Diabetes Dataset**, which contains medical information used to predict diabetes.

### Input Features

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI (Body Mass Index)
* Diabetes Pedigree Function
* Age

### Output

* **Low Risk**
* **High Risk**

## Installation

### 1. Clone the repository



## Model Training

The machine learning models were trained using the following workflow:

* Data preprocessing
* Missing value handling
* Feature scaling
* Feature engineering
* Train-test split
* Model training
* Hyperparameter tuning
* Model evaluation using:

  * Accuracy
  * Precision
  * Recall
  * F1-score
  * ROC-AUC
  * Cross-validation

The trained model is saved as a `.pkl` file and loaded by the Streamlit application during prediction.
